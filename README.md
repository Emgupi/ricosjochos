# Ricos Jochos — PIA Apps (WinUI 3)

Punto de venta de escritorio para **Ricos Jochos** (hot dogs).  
UI lista; catálogo/inventario/clientes vacíos a propósito (avance).

## Requisitos
- Visual Studio 2022
- Workload: desarrollo de la Plataforma universal de Windows / Windows App SDK
- Compilar en **x64**

## Cómo abrir
```bash
git clone https://github.com/TheRedDragon0223/Pia_Apps.git
```
1. Abre `Pia_Apps.sln` en Visual Studio.
2. Plataforma: **x64**.
3. F5.
